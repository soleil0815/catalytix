In the Catalogue, the CSV button at the top right downloads the collection as a spreadsheet (catalytix-bestand.csv). It contains {% if current_user.is_global_manager %}all books{% else %}the books of your groups and general books{% endif %}, sorted by title – search and filter settings make no difference.

Columns (headings in your language): ID, ISBN, title, subtitle, authors, publisher, published, edition, pages, language, category, tags, location, shelf mark, group (or “General”), copies, available.

  • The file is Excel-compatible: semicolon-separated and UTF-8 with a byte order mark, so accented characters come out right. Just double-click it.
  • Formula protection: cells starting with =, +, - or @ get a leading apostrophe so Excel never runs them as formulas; you may see the apostrophe in the cell.
  • The file contains no personal data – no loans and no users, only the number of available copies.

The ID is the internal book number, which you can also enter at the Circulation desk.
