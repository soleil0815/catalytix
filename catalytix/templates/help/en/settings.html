Administration → Settings controls how the library works. Don't forget Save at the bottom.

  • General: Library name (shown everywhere instead of a product name), Default language (currently {{ f.languages.get(f.default_language, f.default_language) }}) – used for visitors whose browser prefers neither German nor English, and for emails to users who have not chosen a language.
  • Catalogue visibility: {% if f.catalog_all %}currently everyone sees the whole catalogue{% else %}currently readers only see their groups' books and general books{% endif %}. Borrowing is always limited to the reader's own groups.
  • Legal: addresses of the Legal notice and Privacy policy. The links appear on the sign-in page, in the sidebar and in every email.
  • Loans: loan period (currently {{ f.loan_days }} {{ "day" if f.loan_days == 1 else "days" }}), renewal by {{ f.extension_days }} {{ "day" if f.extension_days == 1 else "days" }}, at most {{ f.max_extensions }} {{ "time" if f.max_extensions == 1 else "times" }}, simultaneous loans {% if f.max_loans %}at most {{ f.max_loans }}{% else %}unlimited (0){% endif %}.
  • Self-service: Self-checkout ({{ "on" if f.self_checkout else "off" }}), Self-renewal ({{ "on" if f.self_extend else "off" }}), Self-return ({{ "on" if f.self_return else "off" }}). Whatever is off is done by librarians.
  • Reserving ({{ "on" if f.reservations else "off" }}): when all copies are on loan, readers can reserve a book. A copy that becomes free is kept for the first person in the queue for {{ f.hold_days }} {{ "day" if f.hold_days == 1 else "days" }} (email, note on the overview), then the next person gets it. Max. reservations per person limits open reservations (0 = unlimited). Readers cannot extend reserved books themselves. Switching it off deletes all open reservations.
  • Self-registration – see its own topic.
  • Retention – deletion period for completed loans, currently {% if f.retention_months %}{{ f.retention_months }} {{ "month" if f.retention_months == 1 else "months" }}{% else %}never{% endif %}.
  • Two-factor authentication – requirement and internal network, see its own topic.
  • ISBN data sources – German National Library, Open Library, Google Books: tick or untick. They are queried in this order and missing fields are filled from the next source. The server needs internet access for this; only the ISBN is sent.
