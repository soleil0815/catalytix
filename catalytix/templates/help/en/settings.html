Administration → Settings controls how the library works. The page has six tabs; each has its own Save button at the bottom and saves only its own fields.

General

  • Library name (shown everywhere instead of a product name), Default language (currently {{ f.languages.get(f.default_language, f.default_language) }}) – used for visitors whose browser prefers neither German nor English, and for emails to users who have not chosen a language.
  • Catalogue visibility: {% if f.catalog_all %}currently everyone sees the whole catalogue{% else %}currently readers only see their groups' books and general books{% endif %}. Borrowing is always limited to the reader's own groups.

Lending

  • Loan period (currently {{ f.loan_days }} {{ "day" if f.loan_days == 1 else "days" }}), renewal by {{ f.extension_days }} {{ "day" if f.extension_days == 1 else "days" }}, at most {{ f.max_extensions }} {{ "time" if f.max_extensions == 1 else "times" }}, simultaneous loans {% if f.max_loans %}at most {{ f.max_loans }}{% else %}unlimited (0){% endif %}.
  • Self-service: Self-checkout ({{ "on" if f.self_checkout else "off" }}), Self-renewal ({{ "on" if f.self_extend else "off" }}), Self-return ({{ "on" if f.self_return else "off" }}). Whatever is off is done by librarians.
  • Reserving ({{ "on" if f.reservations else "off" }}): when all copies are on loan, readers can reserve a book. A copy that becomes free is kept for the first person in the queue for {{ f.hold_days }} {{ "day" if f.hold_days == 1 else "days" }} (email, note on the overview), then the next person gets it. Max. reservations per person limits open reservations (0 = unlimited). Readers cannot extend reserved books themselves. Switching it off deletes all open reservations.

Catalogue

  • ISBN data sources – German National Library, Open Library, Google Books: tick or untick. They are queried in this order and missing fields are filled from the next source. The server needs internet access for this; only the ISBN is sent.
  • Reading samples – Allow reading samples from Google Books (off by default): the book page shows Reading sample. Without an own Google API key Google answers no queries (daily limit 0) – then the button appears for every book with an ISBN, and Google's viewer says itself when there is no preview. With a key (free in the Google Cloud Console: enable the Books API, create a key and restrict it to the Books API) the server checks beforehand (only the ISBN), and the button appears only for books Google Books knows (whether there is a preview only the viewer shows – Google's own information on that is unreliable); the ISBN lookup via Google Books uses it too. The key is stored encrypted. The browser loads the sample itself from Google only after a click and a notice (two-click solution) – this belongs in your privacy policy. Texts or pages of the sample are not stored; neither copyright nor Google allows that.

Accounts

  • Self-registration – see its own topic.

Security

  • Two-factor authentication – requirement and internal network, see its own topic.
  • Passkeys – Allow sign-in with a passkey (off by default) shows “Sign in with a passkey” on the sign-in page. A passkey counts as two factors; no further prompt follows. AD accounts are checked through the service account on every passkey sign-in (disabled, expired, locked out or no longer authorized – no sign-in); without a service account, or while AD cannot be reached, they can only use their password. An expired AD password does not stop a passkey sign-in. Anyone without a passkey sees a suggestion to set one up on the overview, if their device can hold passkeys.
  • Automatic sign-out – after how many hours without activity everyone is signed out (default 12), an own, shorter limit for admins (default 60 minutes) and optionally for sign-ins from outside. The shortest applicable limit applies. If enabled, “You will be signed out in 2 minutes – keep working?” appears two minutes before. With Sign out when the browser is closed, every sign-in ends with the browser and “Stay signed in” is no longer offered. Where a shorter limit applies (admins, from outside), “Stay signed in” is not available anyway.

Privacy

  • Legal notice and privacy policy: addresses of the Legal notice and Privacy policy. The links appear on the sign-in page, in the sidebar and in every email.
  • Retention – deletion period for completed loans, currently {% if f.retention_months %}{{ f.retention_months }} {{ "month" if f.retention_months == 1 else "months" }}{% else %}never{% endif %}.
