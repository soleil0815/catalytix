Authenticator app (e.g. Microsoft/Google Authenticator, Aegis, 2FAS):

  1. Click Set up app and scan the QR code (or type in the key).
  2. Enter the 6-digit code from the app and click Confirm.
  3. Write down or print the 10 recovery codes – they are shown only now, and each works once.

Security key (YubiKey, passkey): enter a name, click Add and touch the key. This only works over HTTPS and only at the address where the key was registered. Registering a spare key straight away is a good idea.{% if not f.https %} You are not connected over HTTPS right now – only the app works here.{% endif %}

{% if f.passkey_login %}

Passkey – sign in without a password (top box): enter a device name (e.g. “iPhone”, empty = detected), click Create passkey and confirm with your fingerprint, face or PIN. It is stored in Windows Hello, on your phone, in a password manager or on a security key with a PIN. After that, Sign in with a passkey on the sign-in page is all it takes. A passkey also counts as a second factor. Like security keys, it only works over HTTPS and at the address where it was set up. If your device can hold passkeys (Face ID, Touch ID, Windows Hello, Android), the overview suggests it too – Set up a passkey does it there in one step; Later hides the suggestion on this device for 30 days, Don't show again for good.

{% endif %}

Running out of codes? Generate new codes creates fresh ones – the old ones stop working.

Lost your phone? Under Signed-in devices, Sign out on all other devices signs you out everywhere else, including “Stay signed in”. You can then sign in with a recovery code – or ask an administrator to reset your two-factor authentication.
