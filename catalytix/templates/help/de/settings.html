Unter Administration → Einstellungen legen Sie fest, wie die Bibliothek arbeitet. Die Seite hat sechs Reiter; jeder hat unten seinen eigenen Knopf Speichern und speichert nur seine eigenen Felder.

Allgemein

  • Name der Bibliothek (erscheint überall statt eines Programmnamens), Standardsprache (derzeit {{ f.languages.get(f.default_language, f.default_language) }}) – gilt für Besucher, deren Browser weder Deutsch noch Englisch bevorzugt, und für E-Mails an Benutzer ohne eigene Wahl.
  • Katalog-Sichtbarkeit: {% if f.catalog_all %}derzeit sehen alle den gesamten Katalog{% else %}derzeit sehen Leser nur Bücher ihrer Gruppen und allgemeine Bücher{% endif %}. Ausleihen bleibt in jedem Fall auf die eigenen Gruppen beschränkt.

Ausleihe

  • Leihfrist (derzeit {{ f.loan_days }} {{ "Tag" if f.loan_days == 1 else "Tage" }}), Verlängerung um {{ f.extension_days }} {{ "Tag" if f.extension_days == 1 else "Tage" }}, höchstens {{ f.max_extensions }}-mal, gleichzeitige Ausleihen {% if f.max_loans %}höchstens {{ f.max_loans }}{% else %}unbegrenzt (0){% endif %}.
  • Selbstbedienung: Selbstausleihe ({{ "an" if f.self_checkout else "aus" }}), Selbst verlängern ({{ "an" if f.self_extend else "aus" }}), Selbst zurückgeben ({{ "an" if f.self_return else "aus" }}). Ist etwas aus, erledigen das Verwalter.
  • Vormerken ({{ "an" if f.reservations else "aus" }}): Sind alle Exemplare verliehen, können Leser ein Buch vormerken. Ein frei gewordenes Exemplar liegt {{ f.hold_days }} {{ "Tag" if f.hold_days == 1 else "Tage" }} für die erste Person der Warteschlange bereit (E-Mail, Hinweis auf der Übersicht), danach ist die nächste dran. Max. Vormerkungen je Person begrenzt die offenen Vormerkungen (0 = unbegrenzt). Vorgemerkte Bücher können Leser nicht selbst verlängern. Ausschalten löscht alle offenen Vormerkungen.

Katalog

  • ISBN-Datenquellen – Deutsche Nationalbibliothek, Open Library, Google Books: an- oder abwählen. Abgefragt wird in dieser Reihenfolge, fehlende Felder ergänzt die nächste Quelle. Der Server braucht dafür Internetzugang; übertragen wird nur die ISBN.
  • Leseproben – Leseproben von Google Books erlauben (standardmäßig aus): Auf der Buchseite erscheint Leseprobe. Ohne eigenen Google-API-Schlüssel beantwortet Google keine Abfragen (Tageslimit 0) – dann erscheint der Knopf bei jedem Buch mit ISBN, und Googles Viewer zeigt selbst an, wenn es keine Vorschau gibt. Mit Schlüssel (kostenlos in der Google Cloud Console: Books API aktivieren, Schlüssel anlegen und auf die Books API beschränken) prüft der Server vorab (nur die ISBN), und der Knopf erscheint nur bei Büchern, die Google Books kennt (ob es eine Vorschau gibt, zeigt erst der Viewer – Googles eigene Angabe dazu ist unzuverlässig); auch die ISBN-Abfrage über Google Books nutzt ihn. Der Schlüssel wird verschlüsselt gespeichert. Die Leseprobe selbst lädt der Browser erst nach einem Klick und einem Hinweis von Google (Zwei-Klick-Lösung) – das gehört in die Datenschutzerklärung. Texte oder Seiten der Leseprobe werden nicht gespeichert; das erlauben weder Urheberrecht noch Google.

  • Selbstregistrierung – siehe eigenes Thema.

Sicherheit

  • Zwei-Faktor-Anmeldung – Pflicht und internes Netz, siehe eigenes Thema.
  • Passkeys – Anmeldung mit Passkey erlauben (Standard aus) zeigt auf der Anmeldeseite „Mit Passkey anmelden“. Ein Passkey zählt als zwei Faktoren, danach folgt keine weitere Abfrage. AD-Konten werden bei jeder Passkey-Anmeldung über das Dienstkonto geprüft (deaktiviert, abgelaufen, gesperrt oder nicht mehr berechtigt – keine Anmeldung); ohne Dienstkonto oder wenn das AD nicht erreichbar ist, geht für sie nur das Passwort. Ein abgelaufenes AD-Passwort hindert die Passkey-Anmeldung nicht.
  • Automatische Abmeldung – nach wie vielen Stunden ohne Aktivität alle abgemeldet werden (Standard 12), eine eigene, kürzere Frist für Admins (Standard 60 Minuten) und optional für Anmeldungen von außen. Es gilt die kürzeste passende Frist. Auf Wunsch erscheint zwei Minuten vorher „Sie werden in 2 Minuten abgemeldet – weiterarbeiten?“. Mit Beim Schließen des Browsers abmelden endet jede Anmeldung mit dem Browser; „Angemeldet bleiben“ wird dann nicht mehr angeboten. Wo eine kürzere Frist gilt (Admins, von außen), gibt es „Angemeldet bleiben“ ohnehin nicht.
