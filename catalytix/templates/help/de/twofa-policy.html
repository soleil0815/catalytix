Unter Einstellungen → Zwei-Faktor-Anmeldung legst du fest, wer einen zweiten Faktor braucht – getrennt nach Zugriff von außen und aus dem internen Netz.

  • Pflicht bei Zugriff von außen: niemand, Administratoren, Verwalter und Administratoren oder alle. Derzeit: {% if f.mfa_policy == "all" %}alle Benutzer{% elif f.mfa_policy == "librarians" %}Verwalter und Administratoren{% elif f.mfa_policy == "admins" %}Administratoren{% else %}niemand (freiwillig){% endif %}. Betroffene werden nach der nächsten Anmeldung zur Einrichtung geführt.
  • Im internen Netz – derzeit {% if f.mfa_internal == "skip" %}keine Zwei-Faktor-Abfrage{% elif f.mfa_internal == "optional" %}keine Pflicht{% else %}wie von außen{% endif %}: wie von außen (gleiche Regeln), keine Pflicht (wer 2FA hat, wird trotzdem gefragt) oder keine Zwei-Faktor-Abfrage (Passwort reicht).
  • Internes Netz: ein Netz pro Zeile, z. B. 192.168.10.0/24. {% if f.internal_networks_set %}Es sind eigene Netze eingetragen.{% else %}Derzeit leer – dann gelten alle privaten Netze als intern, auch Docker-Netze. Besser auf euer echtes LAN eingrenzen.{% endif %}

Hinter einem Reverse-Proxy zählt die echte Besucher-Adresse aus X-Forwarded-For (Nginx Proxy Manager, Caddy und Traefik schicken sie mit). Fehlt sie, gilt der Zugriff sicherheitshalber als extern; gefälschte Angaben aus dem Internet werden ignoriert. Unten im Bereich steht, wie deine aktuelle Verbindung eingestuft wird – zum Prüfen einmal vom Handy über mobile Daten aufrufen, dort muss „extern“ stehen.

Eigener Internetanschluss: Rufen interne Rechner die öffentliche Domain auf, gibt der Router sie oft mit eurer öffentlichen IP aus. Trage dann eure feste IP oder euren DynDNS-Namen ein (wird alle 5 Minuten neu aufgelöst).{% if f.own_public_set %} Derzeit ist ein Eintrag gesetzt.{% endif %} Achtung: Auch das Gäste-WLAN kommt über diese Adresse und gilt dann als intern. Sauberer ist ein interner DNS-Eintrag (Split-DNS).

Eine intern ohne zweiten Faktor begonnene Sitzung gilt nicht von außen – dort ist eine neue Anmeldung nötig, „Angemeldet bleiben“ wirkt dann nicht.

Wer im LAN ohne zweiten Faktor angemeldet ist, aber selbst 2FA hat, muss den Code bestätigen, bevor er Faktoren ändert oder in der Administration Sicherheitsrelevantes ändert (Benutzer, Freigaben, 2FA zurücksetzen, Sperren, Einstellungen, Active Directory, E-Mail, Datensicherungen). Erscheinungsbild und Gruppen gehen ohne Rückfrage.
