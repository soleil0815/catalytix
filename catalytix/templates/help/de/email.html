Unter Administration → E-Mail richten Sie den Versand über Ihren SMTP-Server ein. Derzeit ist der E-Mail-Versand {{ "aktiv" if f.mail_on else "nicht aktiv" }}.

  1. E-Mail-Versand aktivieren, dann Server, Port, Verschlüsselung (STARTTLS/587, SSL/TLS/465 oder keine/25 nur intern), Zugangsdaten und Absenderadresse eintragen. Beispiel Microsoft 365: smtp.office365.com:587 mit STARTTLS.
  2. Testmail senden – nutzt die Werte im Formular, auch ungespeichert.
  3. Adresse der Bibliothek eintragen (Aktuelle übernehmen), damit Links in den Mails funktionieren.
  4. Speichern.

Benachrichtigungen:

  • Bestätigung bei Ausleihe (sofort) und bei Rückgabe (standardmäßig aus).
  • Erinnerung vor Fälligkeit – {{ "an" if f.reminder_on else "aus" }}, {{ f.reminder_days }} {{ "Tag" if f.reminder_days == 1 else "Tage" }} vorher, einmal je Ausleihe.
  • Mahnung bei Überfälligkeit – {{ "an" if f.overdue_on else "aus" }}, {% if f.overdue_repeat_days == 1 %}jeden Tag{% else %}alle {{ f.overdue_repeat_days }} Tage{% endif %}, höchstens {% if f.overdue_max %}{{ f.overdue_max }}-mal{% else %}unbegrenzt{% endif %}.
  • Tägliche Übersicht an Verwalter – {{ "an" if f.mail_digest else "aus" }}; nur wenn es in ihren Gruppen Überfälliges gibt.

Erinnerungen und Mahnungen laufen einmal täglich ab {{ "%02d"|format(f.mail_hour) }}:00 Uhr, mehrere Bücher einer Person in einer Mail, nie doppelt. Jetzt versenden startet den Lauf sofort. Fällt eine Datensicherung aus, bekommen Administratoren ebenfalls eine Mail.

Das Versandprotokoll unten zeigt jede Mail mit Status und Fehlermeldung; es wird nach der Aufbewahrungsfrist geleert. Adressen kommen bei AD-Konten aus dem Feld mail, bei lokalen aus der Benutzerverwaltung; jeder kann Mails im Profil abschalten. Das SMTP-Passwort wird verschlüsselt gespeichert.
