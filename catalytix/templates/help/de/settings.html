Unter Administration → Einstellungen legst du fest, wie die Bibliothek arbeitet. Unten Speichern nicht vergessen.

  • Allgemein: Name der Bibliothek (erscheint überall statt eines Programmnamens), Standardsprache (derzeit {{ f.languages.get(f.default_language, f.default_language) }}) – gilt für Besucher, deren Browser weder Deutsch noch Englisch bevorzugt, und für E-Mails an Benutzer ohne eigene Wahl.
  • Katalog-Sichtbarkeit: {% if f.catalog_all %}derzeit sehen alle den gesamten Katalog{% else %}derzeit sehen Leser nur Bücher ihrer Gruppen und allgemeine Bücher{% endif %}. Ausleihen bleibt in jedem Fall auf die eigenen Gruppen beschränkt.
  • Rechtliches: Adressen von Impressum und Datenschutzerklärung. Die Links stehen auf der Anmeldeseite, in der Seitenleiste und in allen E-Mails.
  • Ausleihe: Leihfrist (derzeit {{ f.loan_days }} {{ "Tag" if f.loan_days == 1 else "Tage" }}), Verlängerung um {{ f.extension_days }} {{ "Tag" if f.extension_days == 1 else "Tage" }}, höchstens {{ f.max_extensions }}-mal, gleichzeitige Ausleihen {% if f.max_loans %}höchstens {{ f.max_loans }}{% else %}unbegrenzt (0){% endif %}.
  • Selbstbedienung: Selbstausleihe ({{ "an" if f.self_checkout else "aus" }}), Selbst verlängern ({{ "an" if f.self_extend else "aus" }}), Selbst zurückgeben ({{ "an" if f.self_return else "aus" }}). Ist etwas aus, erledigen das Verwalter.
  • Selbstregistrierung – siehe eigenes Thema.
  • Aufbewahrung – Löschfrist für abgeschlossene Ausleihen, derzeit {% if f.retention_months %}{{ f.retention_months }} {{ "Monat" if f.retention_months == 1 else "Monate" }}{% else %}nie{% endif %}.
  • Zwei-Faktor-Anmeldung – Pflicht und internes Netz, siehe eigenes Thema.
  • ISBN-Datenquellen – Deutsche Nationalbibliothek, Open Library, Google Books: an- oder abwählen. Abgefragt wird in dieser Reihenfolge, fehlende Felder ergänzt die nächste Quelle. Der Server braucht dafür Internetzugang; übertragen wird nur die ISBN.
