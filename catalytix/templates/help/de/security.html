Ein zweiter Faktor schützt Ihr Konto, selbst wenn jemand Ihr Passwort kennt. Sie finden alles unter Sicherheit in der Seitenleiste.

{% if f.has_2fa %}

Status: Bei Ihnen ist die Zwei-Faktor-Anmeldung bereits eingerichtet.{% if f.mfa_required %} Die Zwei-Faktor-Anmeldung ist für Ihr Konto vorgeschrieben – den letzten Faktor können Sie deshalb erst entfernen, wenn ein anderer eingerichtet ist.{% endif %}

{% elif f.mfa_required %}

Status: Für Ihr Konto ist ein zweiter Faktor vorgeschrieben{% if f.mfa_internal != "same" %} (beim Zugriff von außen){% endif %}. Nach der Anmeldung führt Sie das Programm hierher, bis er eingerichtet ist.

{% else %}

Status: Noch nicht eingerichtet. Für Sie ist es freiwillig, aber empfohlen.

{% endif %}

Authenticator-App (z. B. Microsoft/Google Authenticator, Aegis, 2FAS):

  1. Klicken Sie auf App einrichten und scannen Sie den QR-Code (oder tippen Sie den Schlüssel ab).
  2. Geben Sie den 6-stelligen Code aus der App ein und klicken Sie auf Bestätigen.
  3. Notieren oder drucken Sie die 10 Wiederherstellungscodes – sie werden nur jetzt angezeigt, jeder gilt einmal.

Sicherheitsschlüssel (YubiKey, Passkey): Namen eingeben, Hinzufügen, Schlüssel berühren. Funktioniert nur über HTTPS und nur unter der Adresse, unter der er eingerichtet wurde. Am besten gleich einen Ersatzschlüssel registrieren.{% if not f.https %} Sie sind gerade nicht über HTTPS verbunden – hier geht nur die App.{% endif %}

{% if f.passkey_login %}

Passkey für die Anmeldung ohne Passwort: Namen eingeben (z. B. „Laptop“), Passkey hinzufügen und mit Fingerabdruck, Gesicht oder PIN bestätigen. Gespeichert wird er in Windows Hello, auf dem Handy, im Passwortmanager oder auf einem Sicherheitsschlüssel mit PIN. Danach genügt auf der Anmeldeseite Mit Passkey anmelden. Ein Passkey zählt zugleich als zweiter Faktor. Wie Sicherheitsschlüssel funktioniert er nur über HTTPS und unter der Adresse, unter der er eingerichtet wurde.

{% endif %}
