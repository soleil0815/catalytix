Quick capture is for many books at once – for example when setting up or after a delivery.

  1. On the right, under Defaults for new titles, set the group and location for all following books.
  2. Scan an ISBN (or type it and press Enter). The field stays active – just keep scanning.

Depending on the result:

  • New title: the data found is shown; Accept (or Enter) adds the book with one copy. Edit … opens the full form, Discard skips it. With Add new titles automatically there is no prompt at all.
  • Already in stock: +1 copy (or Enter) increases the number; Skip leaves it as it is.
  • Nothing found: Add manually opens the normal form with the ISBN filled in.
  • Invalid ISBN: if the check digit is wrong, nothing is added – just scan again.

The Log on the right lists everything from this session with links to the books. Add shelf marks, tags etc. later via Edit.
