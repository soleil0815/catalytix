Under Administration → Email you set up delivery via your SMTP server. Email delivery is currently {{ "active" if f.mail_on else "not active" }}.

  1. Tick Enable sending emails, then enter Server, Port, Encryption (STARTTLS/587, SSL/TLS/465 or none/25 for internal relays only), credentials and Sender address. Example for Microsoft 365: smtp.office365.com:587 with STARTTLS.
  2. Send test email – uses the values in the form, even unsaved.
  3. Enter the Library address (Use current) so that links in emails work.
  4. Save.

Notifications:

  • Confirmation on loan (immediately) and on return (off by default).
  • Reminder before due date – {{ "on" if f.reminder_on else "off" }}, {{ f.reminder_days }} {{ "day" if f.reminder_days == 1 else "days" }} before, once per loan.
  • Overdue notice – {{ "on" if f.overdue_on else "off" }}, {% if f.overdue_repeat_days == 1 %}every day{% else %}every {{ f.overdue_repeat_days }} days{% endif %}, {% if f.overdue_max %}at most {{ f.overdue_max }} {{ "time" if f.overdue_max == 1 else "times" }}{% else %}unlimited{% endif %}.
  • Daily overview for librarians – {{ "on" if f.mail_digest else "off" }}; only when there is something overdue in their groups.

Reminders and overdue notices run once a day from {{ "%02d"|format(f.mail_hour) }}:00, several books per person in one email, never twice. Send now starts the run immediately. Administrators are also emailed when a backup fails.

The Delivery log at the bottom shows every email with its status and any error; it is cleared after the retention period. Addresses come from the mail attribute for directory accounts and from user management for local ones; everyone can turn emails off in their profile. The SMTP password is stored encrypted.
