Updates and emergency commands run on the server, in the folder containing docker-compose.yml. Your own values (port, time zone …) live in .env; updates never overwrite it, nor ./data or docker-compose.override.yml.

Updating with update.sh:

./update.sh --pull                 # newest version from GitHub (ready-made image)
./update.sh --pull=X.Y.Z           # exactly this version from GitHub
./update.sh catalytix-X.Y.Z.zip    # classic: install a package and build locally
./update.sh                        # rebuild or pull the current version again and restart

With --pull the script fetches the image built by GitHub (ghcr.io/soleil0815/catalytix) together with the matching docker-compose.yml and remembers it in .env; a zip package switches back to building locally.

The script checks the package, makes a backup, only then swaps the program files (on an error the previous ones are restored), builds the image catalytix:VERSION (if that fails, the old container keeps running), restarts, waits until the container reports healthy and then cleans up (older images and zip packages – the previous one is kept for the way back –, old work folders). Options: --no-backup, --no-cache, --prune (only the current state remains), --no-cleanup (no cleanup), -y (no questions), --help. It needs Docker Compose (any version, also the older docker-compose) and unzip, alternatively python3. The database is migrated automatically at start-up.

Reproducible build: the base image and all Python packages are pinned to exact versions (requirements.txt, base image additionally by digest) – every build produces the same image.

Emergency commands – each prefixed with docker compose exec catalytix docker-entrypoint.sh (going through the entrypoint runs them without root rights like the app, so e.g. backups are not owned by root):

  • flask --app wsgi reset-password admin – new password for a local account (also re-enables it)
  • flask --app wsgi reset-2fa admin – reset the second factor
  • flask --app wsgi create-admin emergency – additional local admin account
  • flask --app wsgi backup / list-backups – back up now / list backups
  • flask --app wsgi send-reminders – send reminders now
  • flask --app wsgi apply-retention – apply the retention period now

Most of this is also available in the interface: reset 2FA and lift sign-in locks in the user's account, Back up now, Send now, Clean up now. The version is shown at the bottom of the sidebar; clicking it shows the licence and source code.
